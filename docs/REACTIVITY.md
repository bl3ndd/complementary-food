# Матрица реактивности: мутация → какие экраны обязаны обновиться

Контракт живости UI: каждая мутация данных должна БЕЗ перезапуска обновить все
зависимые экраны. Пинится тестами `UITests/ReactivityUITests.swift` (R1…R9).

## Источники данных экранов (фактические @Query)

| Экран | @Query | Не-реактивные чтения |
|---|---|---|
| RootView | children | — |
| MainTabView (бейдж таба) | statuses, logs | FoodCatalog.shared |
| Dashboard | statuses, logs | ⚠️ `catalog.all.count` (статик) |
| Catalog | statuses, customFoods | FoodCatalog.shared |
| FoodDetail | statuses(id), logs(id, !planned) | — |
| Calendar / DayDetail | logs, statuses, children | FoodCatalog.shared (имена) |
| Allergens | statuses, logs | FoodCatalog.shared (группы) |
| Profile (гейты «Данных») | logs, statuses | — |

⚠️ **Слабое место:** `FoodCatalog.custom` — статик, не observable. Знаменатель
коллекции (`N/72`) на главной пере-читается только когда меняются statuses/logs.
Держится на связке: добавление своего продукта ВСЕГДА делает `markIntroduced`
(меняет statuses), удаление — чистит статус+логи. Если появится путь мутации
custom-каталога без изменения statuses/logs — главная протухнет. R2 пинит.

## Мутация → обязаны обновиться

| Мутация | Dashboard | Catalog | Calendar | Allergens (+бейдж таба) | Profile |
|---|---|---|---|---|---|
| logFeeding (плитка/карточка/«Дал») | hero-счётчик, дневник | — (статус не меняется) | лента/сетка | lastGiven → статус группы | гейты PDF/рекап |
| startIntroduction | «Сейчас вводишь», дневник (intro-лог) | бейдж «Вводится» | лента | — | гейты |
| completeIntroduction | «Сейчас вводишь» −, коллекция + | бейдж «Введён» | — | группа может стать due | — |
| stop/resume/retry/markAllergy | «Сейчас вводишь» ± | бейдж | — | «Аллергия»/«Дал», бейдж таба | гейт «не давать» |
| markIntroduced (свой продукт/онбординг) | коллекция N и знаменатель | бейдж «Введён» | — | если аллерген — строка | — |
| Свой продукт: добавить/удалить | коллекция N/знаменатель | секция «Свои продукты» | имена в ленте | — | — |
| План: planned-лог / «Выполнено» / удалить | дневник (после confirm) | — | «ПЛАНЫ», день, дедуп | — | — |
| Правка/удаление лога | дневник, hero-счётчик | история карточки | лента/сетка | lastGiven | гейты |
| План прикорма: группы аллергенов | витрина аллергенов | — | — | набор строк групп | сводка плана |
| resetAll | → онбординг (children) | — | — | — | — |

## Тесты-хранители (ReactivityUITests)

- **R1** кормление с плитки → дневник + лента календаря + гейт рекапа в профиле
- **R2** свой продукт: добавить → коллекция `1/72`; удалить → `0/71`
- **R3** старт ввода → «Сейчас вводишь» + дневник + бейдж «Вводится» в каталоге
- **R4** окно закрылось само → «Сейчас вводишь» − , коллекция +1, бейдж «Введён»
- **R5** «Дал» аллерген → строка «В норме» + запись в ленте календаря
- **R6** «Пометить аллергию» → бейдж «Аллергия», «Дал» исчез
- **R7** план → «ПЛАНЫ» в ленте → «Выполнено» → запись в дневнике главной
- **R8** снять группу в плане → строка ушла с таба Аллергены (и обратно)
- **R9** удалить запись в календаре → hero-счётчик главной уменьшился
