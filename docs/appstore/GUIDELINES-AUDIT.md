## Что делать перед Submit

1. 🔴 Собрать и залить **новый билд** (после `xcodegen generate` — в проект добавился
   `Resources/PrivacyInfo.xcprivacy`), прицепить его к версии вместо build 1.
2. 🔴 App Privacy → «Data Not Collected» → **Save и Publish** (только веб-UI; в ASC API
   таких эндпоинтов нет).
3. 🔴 CloudKit Console → **Deploy Schema to Production**.
4. ⚠️ Подтвердить support-email.
5. ⚠️ Решить по Content Rights (см. 5.2.1).

Закрыто через API 11.08: номер версии `1.0` → `1.0.0`, Review Notes (фоновый режим +
5.1.3(ii) + «Data Not Collected»), `ageRatingDeclaration.socialMedia = false`.
Политика со сроком хранения уехала на прод автодеплоем Vercel.
