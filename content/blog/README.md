# Статьи блога

Один каталог — одна статья: `content/blog/<slug>/<lang>.json`, по файлу на язык
(коды те же, что `LANGS` в `scripts/landing/build.py`). Оригинал пишется на `en`,
остальные — переводы.

```json
{
  "title": "Заголовок статьи",
  "description": "Мета-описание, ~150 символов",
  "keyword": "целевой запрос",
  "date": "2026-08-14",
  "body": "markdown: абзацы, ## и ###, списки, **жирный**, *курсив*, [ссылки](/en), `код`"
}
```

Руками сюда обычно не пишут — статью генерит `scripts/write_article.py`
(еженедельный GitHub Action). Правки в существующих статьях делать можно, но
`date` не трогать: он идёт в `<lastmod>` sitemap.

Разметка в `body` — только то подмножество, которое понимает `scripts/landing/md.py`.
HTML экранируется целиком, теги в теле не сработают.
